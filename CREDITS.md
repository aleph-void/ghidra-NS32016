# Credits: National Semiconductor NS32016 module (NS32016, NS32081 FPU, NS32082 MMU, NS32532)

This module is a community SLEIGH module that Ghidra-Rare imported, tested and rewrote. The
original project, its Ghidra extension structure and the first instruction patterns were written by
the author below; Ghidra-Rare's changes are listed after them.

Ghidra-Rare's changes are separate commits on branch `ghidra-rare` of a fork of the upstream
repository, on top of its full history, so the original license and authorship are preserved.

No other NS32016 implementation was found on GitHub. The MAME ns32000 core (BSD-3-Clause) and GNU
binutils `ns32k` (run as a black box, plus its opcode table read at test time and not committed)
were used as references; no code was copied from either. The NetBSD 1.5 pc532 programs used for
real-code tests are fetched by pinned URL and SHA-256 and are not committed.

## Ghidra-Rare changes

The upstream module was a stub (146 constructors with empty p-code, a catch-all `UNK`, `R3`
attached twice, index modes exporting 0, a shared displacement table). It was replaced by
generated sources; see `GHIDRA-RARE.md` for the test results.

1. **Complete NS32016/NS32081/NS32082 specification with p-code**, generated by
   `tools/gen_ns32016.py` (`aee971a`).
2. **NS32532 variant** (`NS32016:LE:32:NS32532`): NS32381 FPU model, on-chip MMU, extra registers,
   CINV (`cf7b034`).
3. **NetBSD/pc532 a.out loader** (`495f80a`).
4. **README** rewritten with install notes and the status of the upstream limitations (`b025dac`).
5. **Notes, tests and build files**: `GHIDRA-RARE.md`, `test/`, `build.gradle`,
   `extension.properties`, the release workflow (`227532c` and the workflow commit).
